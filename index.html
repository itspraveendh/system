Important Data Security Rules:
  • Do not apply delete operations indiscriminately to payroll, financial transactions, invoices, or audit records. Use appropriate cancellation, reversal, or archival workflows.
  • Bulk exports must respect user permissions and exclude unauthorized sensitive information.
  • Provide an import preview, column mapping, validation report, and error summary before committing imported records.
  • Protect against CSV formula injection when exporting untrusted data.
